# 验证范围

兼容目标：Zotero 10.0.8 桌面版。安装清单允许 Zotero 10.0.x；其他主版本尚未声明兼容。

此版本的代码按 Zotero 10.0.8 官方源码中的菜单、设置、全文缓存、HTTP、条目与笔记接口实现。验证环境中未安装真实 Zotero 10.0.8，也没有运行真实 Ollama 模型，因此不能把下列自动测试视为已完成宿主兼容性或模型生成质量实测。

## 自动验证

- 核心逻辑：设置与本机地址校验、输入与来源处理、JSON 输出校验、标签去重、笔记 HTML 转义、云模型拒绝、取消与长度上限。
- Zotero 适配器：通过模拟 Zotero API 验证选择条目、读取本地缓存、保留已有标签、创建子笔记、写权限复查，以及本机 HTTP 请求选项和取消。
- 生命周期：已使用模拟宿主验证作用域加载、菜单与设置注册、窗口桥接和禁用清理。
- 界面：已通过 Chromium/Playwright 和模拟 Zotero/Ollama 桥接，验证配置、生成、编辑、切换条目、批量保存、取消并重试、保存失败保留草稿和禁止重复保存。测试使用实际 XHTML 内部控件、CSS、脚本和核心逻辑，将 XUL 外层替换为浏览器容器，不会运行 XUL 宿主本身。
- 打包脚本：校验清单、必要文件和 ZIP 完整性，使用排序与固定时间戳生成可复现归档。

交付验证：核心、适配器和生命周期共 **28 项**通过；Chromium 界面测试 **4 项**通过；XHTML 为有效 XML。测试命令和依赖说明见 [README.md](../README.md)。界面预览取自模拟数据，不能证明真实模型的生成质量。

真实宿主测试受当前环境限制：未预装 Zotero；访问 Zotero 官方二进制下载地址返回代理 HTTP 403，因此未安装真实 Zotero。代码接口已对照 10.0.8 官方源码核对。这是待本机验证的预览版。

## 待真实环境验证

1. 在 Zotero 10.0.8 中通过 XPI 安装，确认菜单、设置入口和生成窗口正常显示。
2. 启动本机 Ollama，下载并选择模型，确认列表检测及真实 JSON 生成可用。
3. 用一篇仅有标题/摘要的文献，以及一篇有本地索引 PDF 的文献，检查来源提示和简记内容。
4. 修改结果并保存，确认原标签与笔记保留、新子笔记关联到正确文献。
5. 多选文献，验证批量、停止、请求超时，以及只读库和被删除条目的报错。
6. 禁用/启用插件并重启 Zotero，确认界面和设置状态正常。

这些检查使用用户自己选择的测试文献进行；模型输出需要对照原文检查。
